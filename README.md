# speech2speech

A conversation between two people in two languages, on one device.

One side speaks into the microphone, the other side reads the translation and can
have it read aloud. Both sides have a name and a language, and either side can
also type. Conversations are kept, so you can read one again or carry it on.

Everything runs on models you choose. With a self hosted endpoint the audio and
the text stay in your network.
